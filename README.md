**Stack:** `Java 21` `Spring Boot` `Spring AI` `Ollama` `DeepSeek-R1` `React` `Vite` `Tailwind CSS`

**Stack:** `Java 21` `Spring Boot` `Spring Security` `Thymeleaf` `PostgreSQL` `Cloudinary` `Docker`
